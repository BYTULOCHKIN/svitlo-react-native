# 03. Видалення локацій і повернення до вибору черги

Статус: виконано; реалізація та автоматизовані перевірки завершені. Платформне приймання — issue 10.
Джерело: [PRD](../svitlo-react-native-migration.prd.md).

Тип: AFK. User stories: 10–12, 25, 28.

## What to build

Користувач видаляє локацію через наявний сценарій редагування. Видалення активної локації переводить його на одну з решти, а видалення останньої повертає до явної пропозиції вибрати чергу. Дані не відновлюються помилково після перезапуску.

## Acceptance criteria

- [x] Видалення неактивної локації не змінює поточний графік.
- [x] Після видалення активної локації за наявності інших вибирається перша з решти, відповідно до Kotlin-поведінки.
- [x] Останню локацію можна видалити; активний вибір очищується, персональні статус і таймер зникають.
- [x] Порожній стан містить явний заклик обрати чергу; повторний вибір знову створює «Дім».
- [x] Видалення збережене між запусками й не скасовується пізнім результатом запиту.
- [x] Unit-тести покривають видалення неактивної, активної та останньої локації; TypeScript і ESLint проходять.

## Validation

Видалення неактивної, активної та останньої локації, збереження після перезапуску й повторний вибір черги перевірені. Повний набір: 52/52 тестів.

TypeScript та ESLint пройдено. Jest пройдено; наявні попередження демонстраційної форми Obytes не належать продуктовому сценарію Svitlo. Нативне приймання не заявляється виконаним.
