# 01. Перший запуск, вибір черги та реальний поточний стан

Статус: реалізовано та перевірено; коміт очікує налаштування Git user.name/user.email. Платформний запуск перевіряється в issue 10.
Джерело: [PRD](../svitlo-react-native-migration.prd.md).

Тип: AFK. User stories: 1–6, 12–14, 20, 25–26, 28.

## What to build

Користувач відкриває застосунок, бачить пропозицію обрати чергу, отримує список черг Полтаваобленерго, вибирає свою та переходить до головного екрана з локацією «Дім» і поточним станом. Вибір зберігається після перезапуску.

У цьому сценарії замінити стартові маршрути Obytes на навігацію Svitlo з головною вкладкою, вкладкою черг та порожньою вкладкою сповіщень. Вкладка черг до задачі 06 ще не надає загальної таблиці. Не показувати демонстраційний вхід, feed або onboarding. Налаштувати окрему локальну ідентичність застосунку для платформ; прив’язка до EAS-акаунта та публікація не є частиною задачі.

Запит і HTML-парсер сховати за адаптером оператора, вибір і збереження — за сховищем локацій, поточний стан — за незалежною від React моделлю графіка. Отримати фактичний приклад відповіді й задокументувати її контракт. Таймер і часова шкала додаються в задачі 04.

## Acceptance criteria

- [x] При чистому запуску немає локацій та обраної черги; є текст «Оберіть свою чергу, щоб побачити графік відключень» і дія вибору.
- [x] До вибору черги немає персонального статусу та таймера.
- [x] Доступні черги отримуються з нормалізованої відповіді оператора; не підставляється черга 3.1 або демонстраційний графік.
- [x] Вибір створює активну локацію «Дім» з іконкою дому та правильною чергою, яка відновлюється після перезапуску.
- [x] Картка розрізняє «є світло», «немає світла», «можливе відключення» та «немає даних»; невідомий тип не стає наявністю світла.
- [x] Завантаження, помилка запиту та відсутність черги у відповіді мають окремі зрозумілі стани.
- [x] Парсер враховує rowspan, півгодинні клітинки, `24:00` і об’єднує лише суміжні однакові типи.
- [x] Збережено українські тексти, базове компонування, кольори та нижню навігацію за Kotlin-кодом; вкладка сповіщень порожня.
- [x] Налаштована окрема ідентичність збірки; шаблонний EAS-проєкт Obytes не використовується як проєкт Svitlo.
- [x] Парсер і поточний стан перевірені на контрольованих фікстурах; новий код проходить TypeScript і ESLint. Додатковий компонентний тест першого вибору — пропозиція з PRD, що потребує підтвердження обсягу тестів.
