# 05. Підтверджений стан без запланованих відключень

Статус: виконано; реалізація та автоматизовані перевірки завершені. Платформне приймання — issue 10.
Джерело: [PRD](../svitlo-react-native-migration.prd.md).

Тип: AFK. User stories: 14–16, 20, 28.

## What to build

Користувач бачить «Відключення не заплановані на сьогодні», коли оператор явно підтверджує це для вибраної черги або повертає повний графік дня лише зі світлом. Розпізнавання проходить від відповіді оператора через нормалізовану модель до головного екрана.

Отримати та перевірити фактичний формат явного повідомлення. Якщо його зразок недоступний, документувати це обмеження: не вигадувати маркер і не стверджувати, що ця гілка перевірена. Підтвердження для всіх черг можна застосовувати до вибраної лише коли це випливає зі змісту відповіді.

## Acceptance criteria

- [x] Повний день зі станом «є світло» дає погоджений текст для вибраної черги.
- [x] Явна відповідь оператора розпізнається за перевіреним контрактом, з урахуванням дати й області її дії.
- [x] Якщо явна відповідь не містить переліку черг, наявний вибір локації не втрачається; поведінка першого вибору не використовує вигадані доступні черги.
- [x] Порожня відповідь, неповний день, невідома клітинка, відсутня черга та помилка запиту не стають станом без запланованих відключень.
- [x] Картка не показує відлік до вигаданого відключення; модель надає результат, який задача 04 може використати без окремого парсингу в UI.
- [x] Unit-тести покривають позитивні й негативні умови на перевірених фікстурах; неперевірені формати явно зазначені.
- [x] TypeScript і ESLint проходять.

## Validation

Перевірено фактичне обласне повідомлення оператора з датою, додано фікстуру та безпечне розпізнавання. Повний день лише зі світлом також підтверджує стан; порожні й неповні дані не підтверджують. 59/59 тестів пройдено.

TypeScript та ESLint пройдено. Jest пройдено; наявні попередження демонстраційної форми Obytes не належать продуктовому сценарію Svitlo. Нативне приймання не заявляється виконаним.
