# Перевірений контракт Полтаваобленерго

10 жовтня 2026 року виконано POST до `https://www.poe.pl.ua/customs/newgpv-info.php` з form-urlencoded полем `seldate={"date_in":"10-10-2026"}` та заголовком `X-Requested-With: XMLHttpRequest`.

Отримано HTTP 200 та HTML: таблиця `turnoff-scheduleui-table`, tbody з дванадцятьма підчергами, назва черги з rowspan, 48 півгодинних клітинок на день. Класи `light_1`, `light_2`, `light_3` відповідають типам оригінального Kotlin-парсера. Кінець 48-ї клітинки — 24:00.

Відповідь збережено як JSON-фікстуру для повторюваних тестів без мережі. Фікстура не використовується як fallback у застосунку.

Порожній HTML або невідома структура не підтверджують відсутність відключень. Формат явного повідомлення без графіка потребує окремої перевірки в issue 05.

Локальна ідентичність застосунку: `ua.svitlo.rn` із суфіксами середовищ. Expo/EAS account і project ID задаються лише через `EXPO_ACCOUNT_OWNER` та `EAS_PROJECT_ID`; значення Obytes прибрані. Це не налаштування публікації.
