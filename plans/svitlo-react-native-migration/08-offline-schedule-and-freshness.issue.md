# 08. Збережений графік без інтернету

Статус: виконано; реалізація та автоматизовані перевірки завершені. Платформне приймання — issue 10.
Джерело: [PRD](../svitlo-react-native-migration.prd.md).

Тип: AFK. User stories: 12–16, 20, 22–24, 28.

## What to build

Після успішного отримання графік зберігається локально з датою та часом оновлення. Користувач повторно відкриває застосунок без інтернету і бачить збережені дані з позначкою. Прострочений графік не керує сьогоднішнім статусом або таймером.

## Acceptance criteria

- [x] Успішна нормалізована відповідь, включно з підтвердженим станом без відключень, зберігається з датою графіка та часом отримання.
- [x] Після перезапуску й невдалого запиту доступний останній збережений графік та список локацій.
- [x] Позначка кешу, помилка оновлення та час останнього успіху не створюють враження щойно отриманих даних; мережеву помилку не називати відсутністю інтернету без підстав.
- [x] Поточний збережений графік дозволяє користуватися погодженими статусами та шкалою з позначкою актуальності.
- [x] Дані попереднього дня позначені як попередні й не визначають сьогоднішні статус, відлік або повідомлення про відсутність запланованих відключень.
- [x] За відсутності, пошкодженні або несумісності кешу застосунок не падає та не підставляє графік.
- [x] Відновлення зв’язку та успішне ручне оновлення замінюють кеш і очищують попередню помилку.
- [x] Unit-тести перевіряють відновлення та прострочення; інтеграційні тести запису, перезапуску й помилок сховища є запропонованим додатковим покриттям PRD.
- [x] TypeScript і ESLint проходять.
