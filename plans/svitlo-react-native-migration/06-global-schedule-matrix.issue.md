# 06. Загальна таблиця всіх черг

Статус: виконано; реалізація та автоматизовані перевірки завершені. Платформне приймання — issue 10.
Джерело: [PRD](../svitlo-react-native-migration.prd.md).

Тип: AFK. User stories: 14, 20–21, 25, 28.

## What to build

Користувач переходить на вкладку черг і бачить загальну таблицю Полтаваобленерго з виділенням своєї активної черги. Таблиця використовує ту саму нормалізовану відповідь, що й головний екран, і відтворює компонування Kotlin.

## Acceptance criteria

- [x] Показані черги, підчерги, часова сітка й легенда відповідно до фактично використовуваного Kotlin-компонента.
- [x] Є світло, відключення, можливе відключення та невідомий стан відображаються послідовно з головним екраном.
- [x] Активна черга виділена; якщо локація не вибрана, таблиця доступна без помилкового виділення.
- [x] Зміна активної локації оновлює виділення без окремого HTML-парсингу або дубльованого запиту.
- [x] Завантаження, відсутні дані й помилка мають зрозуміле відображення.
- [x] Таблиця придатна для прокручування на телефонах Android та iOS.
- [x] Якщо відтворюється статистика Kotlin-таблиці, вона використовує фактичну тривалість інтервалів; нові розбіжності погоджуються за правилом PRD.
- [x] Перетворення інтервалів у клітинки перевірене unit-тестами; TypeScript і ESLint проходять.

## Blocked by

## Validation

Таблицю перенесено за Kotlin-кодом зі спільного графіка: середина години, фактична тривалість світла, сортування й виділення активної черги. Невідомі дані не зараховуються як світло. 60/60 тестів пройдено.

TypeScript та ESLint пройдено. Jest пройдено; наявні попередження демонстраційної форми Obytes не належать продуктовому сценарію Svitlo. Нативне приймання не заявляється виконаним.
