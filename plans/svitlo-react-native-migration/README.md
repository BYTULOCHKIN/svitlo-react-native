# Issues: перенесення Svitlo на React Native

Статус: виконані issues 01–04; кожна зберігається окремим комітом. Решта очікують реалізації або потрібного погодження. Платформне приймання ще не виконане.

Джерело: [PRD](../svitlo-react-native-migration.prd.md).

Завершення задачі означає виконання її критеріїв приймання; погодження поділу не означає виконання задач або наперед надане погодження конкретних виправлень у HITL-задачах.

Додаткові інтеграційні та компонентні тести залишаються пропозицією PRD; окремого підтвердження їх обсягу наразі немає.
