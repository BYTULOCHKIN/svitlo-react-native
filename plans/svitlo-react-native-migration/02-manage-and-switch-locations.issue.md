# 02. Додавання, редагування й перемикання локацій

Статус: виконано; реалізація та автоматизовані перевірки завершені. Платформне приймання — issue 10.
Джерело: [PRD](../svitlo-react-native-migration.prd.md).

Тип: AFK. User stories: 7–9, 12–14, 25, 28.

## What to build

Користувач додає другу локацію, вибирає її назву, чергу й іконку, перемикається між локаціями та редагує їх. Головний екран показує стан активної локації, а зміни відновлюються після перезапуску. Селектор і діалог відтворюють Kotlin-компоненти.

## Acceptance criteria

- [x] Доступне додавання локації з назвою, чергою зі списку оператора та іконками, представленими в Kotlin-коді.
- [x] Нова локація стає активною, як у Kotlin, і показує власний графік.
- [x] Редагування активної локації оновлює її відображення та стан; зміна черги не залишає графік попередньої черги.
- [x] Перемикання локації не повторює запит без потреби, коли графіки потрібної дати вже завантажені.
- [x] Перелік локацій зберігається після перезапуску; поведінку збереження активного вибору явно описано як технічне уточнення PRD.
- [x] Незавершений запит попереднього вибору не перезаписує стан поточної локації.
- [x] Селектор та діалоги відповідають Kotlin-коду й придатні для роботи з клавіатурою на обох платформах.
- [x] Поведінка операцій зі сховищем перевірена unit-тестами; TypeScript і ESLint проходять.
