# 03. Адаптивна сітка черг та іконок у формі

Тип: AFK.

Статус: реалізовано; перевірка на пристроях — задача 06.

Джерело: [PRD](../svitlo-component-foundation.prd.md).

User stories PRD: 23, 24, 25, 42, 43, 45, 46, 50, 51, 52, 54, 55, 57.

## What to build

Обрати іконку та чергу через спільний AppChoiceGrid безпосередньо у формі й зберегти отриману локацію. Сітка використовує контрольоване значення, адаптивну кількість колонок та доступне позначення вибору.

## Acceptance criteria

- [x] Черги показані вбудованою сіткою, без нижньої панелі поверх форми; іконки мають зрозумілі доступні назви.
- [x] Вибір відображається позначкою й доступним станом checked, додатково до кольору; заблокований пункт не активується.
- [x] Кількість колонок адаптується до ширини та системного шрифту; зона натискання кожного пункту щонайменше 48 × 48 dp.
- [x] Три символи є типовою довжиною черги, а не новим обмеженням моделі; довші значення не обрізаються мовчки.
- [x] Компонентні й інтеграційні тести перевіряють контрольовану зміну значення, відсутність неявного вибору та збереження вибраної іконки й черги.
- [x] TypeScript, lint і релевантні тести проходять.

AppChoiceGrid побудований на gluestack Radio; кількість колонок залежить від onLayout та fontScale, мінімальні розміри — 48 × 48 dp. Вибір має checked та Lucide Check. Довгі черги не обрізаються; компонентні тести захищають контрольоване значення, порожній вибір і disabled. Інтеграційні тести записують іконку та чергу. TypeScript, lint і регресійний набір пройшли; фактичне компонування при найбільшому шрифті приймається в задачі 06.
