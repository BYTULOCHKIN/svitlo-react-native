# 01. Додавання локації на gluestack

Тип: AFK.

Статус: реалізовано; native-приймання — задача 06.

Джерело: [PRD](../svitlo-component-foundation.prd.md).

User stories PRD: 18, 20, 21, 22, 26, 27, 28, 39, 40, 41, 43, 44, 54, 55, 57, 58.

## What to build

Пройти шлях від дії додавання локації до успішно збереженої активної локації через AppDialog, AppInput, AppButton та AppText. Інтегрувати gluestack із поточними Expo/UniWind і токенами; на першому кроці зберегти існуючі вибори іконки та черги. Почати контрольований продуктовий E2E-сценарій створення без авторизації.

## Acceptance criteria

- [x] Обрані й зафіксовані сумісні версії gluestack та потрібних залежностей; поточні Expo/React Native збережені, або суттєва зміна стеку винесена на окреме погодження.
- [x] Форма додавання реально використовує спільні діалог, поле, текст і кнопки, з поточною темною темою та Inter.
- [x] Порожня назва, назва з пробілів і відсутня черга блокують запис; ліміт 20 символів та очищення крайніх пробілів збережені.
- [x] Успішне створення робить локацію активною; помилка запису залишає форму й чернетку та показує доступне повідомлення.
- [x] Діалог враховує safe area, прокручування та клавіатуру; створення не порушує існуючий сценарій редагування.
- [x] Додано поведінкові компонентні й інтеграційні тести та продуктовий E2E-сценарій додавання з ізольованими даними; TypeScript, lint і релевантні тести проходять.

Зафіксовано core 5.0.15 і utils 5.0.6. Додавання використовує спільну форму; компонентні/інтеграційні тести перевіряють валідацію, trim, вибір нової локації та retry після помилки MMKV. Додано ізольований [E2E flow](../../.maestro/svitlo/01-add-location.yaml). TypeScript, lint, 114 тестів і export Android/iOS/web пройшли. Native E2E ще не виконано; результат фіксується в задачі 06.
