# 11. Базова робота web і сумісність старих споживачів

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-component-foundation.prd.md).

User stories PRD: 53, 54, 55, 57, 60.

## What to build

Запустити браузерну версію та пройти вибір черги, список локацій, форму й підтвердження; перевірити production-захист каталогу та збереження працездатності немігрованих шаблонних споживачів.

## Acceptance criteria

- [ ] Web-збірка та запуск успішні; основні дії не мають runtime-помилок, вибір і форма працюють.
- [ ] Внутрішній екран недоступний прямим переходом у production.
- [ ] Немігровані шаблонні споживачі компілюються; сумісні адаптери не створюють другу продуктову реалізацію.
- [ ] Залежності й providers видаляються лише після перевірки всіх споживачів; потрібний шаблонам gorhom може залишитися.
- [ ] Повний аудит web-a11y, новий сайт та функції шаблонних екранів не додаються.
- [ ] Результати smoke-перевірки, релевантні регресійні тести, TypeScript, lint і перевірка токенів зафіксовані.
