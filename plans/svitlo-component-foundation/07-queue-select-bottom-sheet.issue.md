# 07. Перший вибір черги в нижній панелі

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-component-foundation.prd.md).

User stories PRD: 4, 5, 6, 7, 8, 9, 10, 11, 12, 37, 39, 40, 42, 43, 45, 46, 47, 48, 49, 50, 51, 53, 54, 55, 57, 58.

## What to build

Відкрити вибір черги з головної, обрати зі спільної сітки в AppSelect/AppSheet та отримати локацію «Дім». Реалізувати стани завантаження, помилки, порожнього переліку й повтору в цьому самому сценарії.

## Acceptance criteria

- [ ] AppSelect використовує gluestack Select, а мобільний вибір — нижню панель із AppChoiceGrid; AppSheet інкапсулює модальний життєвий цикл.
- [ ] Відкриття не змінює value; успішний вибір викликає зміну один раз і закриває панель; закриття без вибору не змінює значення.
- [ ] Повторне відкриття показує актуальний вибір; зовнішня зміна value/options не створює мовчазної підміни.
- [ ] Loading, error, empty та retry залишаються явними; черги отримуються з наявних даних оператора.
- [ ] Помилка запису першого вибору не створює удаваної локації; успішний вибір відновлюється після перезапуску.
- [ ] Компонентні, інтеграційні та контрольований E2E першого вибору проходять разом із TypeScript і lint.
