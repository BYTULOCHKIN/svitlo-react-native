# 08. Вибір локації та перехід до форми

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-component-foundation.prd.md).

User stories PRD: 13, 14, 15, 16, 17, 18, 19, 42, 43, 45, 46, 47, 48, 49, 50, 51, 54, 55, 57, 58.

## What to build

Відкрити список локацій в AppSheet, перемкнути активну або перейти до додавання/редагування. Перевірити весь цикл повернення до головної зі збереженим вибором.

## Acceptance criteria

- [ ] Рядки містять іконку, назву, чергу та позначення активного стану; довгі назви переносяться.
- [ ] Редагування є окремою кнопкою й не перемикає активну локацію; додавання доступне в цій самій панелі.
- [ ] Перед відкриттям форми панель закривається; немає двох активних модальних контекстів або некоректного фокуса на фоні.
- [ ] Успішний вибір закриває панель і зберігається; помилка запису не змінює підтверджений вибір та пояснює результат.
- [ ] Інтеграційні й E2E-сценарії перевіряють перемикання, додавання, редагування та повернення після скасування.
- [ ] TypeScript, lint і релевантні тести проходять.
