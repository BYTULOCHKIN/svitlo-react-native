# 04. Підтвердження скасування незбережених змін

Тип: AFK.

Статус: реалізовано; Android E2E PASS, ручний TalkBack/VoiceOver focus — задача 06.

Джерело: [PRD](../svitlo-component-foundation.prd.md).

User stories PRD: 29, 30, 31, 32, 47, 48, 49, 57, 58.

## What to build

Редагувати поля, запросити закриття форми й обрати між продовженням редагування та відкиданням чернетки. Додати AppConfirmDialog та єдиний шлях обробки запитів закриття.

## Acceptance criteria

- [x] Незмінена форма закривається одразу; зміна назви, іконки чи черги вмикає підтвердження.
- [x] Повернення до всіх початкових значень прибирає стан незбережених змін.
- [x] Скасування, кнопка закриття, фон і системне повернення використовують одне правило; платформне закриття клавіатури не обходить захист форми.
- [x] «Продовжити редагування» зберігає чернетку; «Відкинути зміни» закриває без запису.
- [ ] Підтвердження ізолює активний модальний контекст і коректно повертає фокус при скасуванні.
- [x] Компонентні, інтеграційні та E2E-тести захищають обидві гілки й відсутність запису після відкидання; TypeScript та lint проходять.

Форма змінює вміст одного AppDialog на AppConfirmDialogBody, зберігаючи чернетку в батьківському компоненті. Безпечна дія отримує запит фокусу, скасування повертає його в поле назви. Інтеграційні тести покривають Cancel, Close, backdrop, native requestClose та accessibility escape, усі три поля, повернення початкових значень, продовження і discard без запису. 10.10.2026 обидві гілки пройшли native E2E на Samsung SM-S928U1, Android 16, fontScale 1.0. Виправлено перехоплення першого натискання клавіатурою в батьківському ScrollView; окремий E2E підтвердив закриття одним натисканням після повернення до чернетки. TypeScript, lint і тести пройшли; реальний TalkBack/VoiceOver focus залишається для задачі 06.
