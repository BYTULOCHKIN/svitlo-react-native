# 05. Незалежний перемикач push про графіки

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 12, 13.

## What to build

Користувач вимикає push про публікації та зміни через загальний перемикач, але продовжує бачити обидва типи в історії. Налаштування зберігається на пристрої та сервері.

## Acceptance criteria

- [ ] Перемикач увімкнений за замовчуванням; стан переживає перезапуск і передається серверу з версією налаштувань.
- [ ] За вимкнення публікації та зміни продовжують створювати записи, але не створюють push для цієї інсталяції.
- [ ] Перемикач не змінює прапорці локацій; подальше додавання попереджень використовує незалежний стан.
- [ ] Повторна або застаріла синхронізація не повертає старе значення. UI доступний screen reader; серверний і компонентний тести перевіряють історію без push.
