# 05. Незалежний перемикач push про графіки

Тип: AFK.

Статус: реалізовано й розгорнуто; автоматичні перевірки та тестова D1 PASS. Production APK build 3 встановлено на Samsung: перемикачі, реальні згруповані push та 200%/320 dp перевірені; ручне перемикання TalkBack підтверджене сервером.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 12, 13.

## What to build

Користувач вимикає push про публікації та зміни через загальний перемикач, але продовжує бачити обидва типи в історії. Налаштування зберігається на пристрої та сервері.

## Acceptance criteria

- [x] Перемикач увімкнений за замовчуванням; стан переживає перезапуск і передається серверу з версією налаштувань.
- [x] За вимкнення публікації та зміни продовжують створювати записи, але не створюють push для цієї інсталяції.
- [x] Перемикач не змінює прапорці локацій; подальше додавання попереджень використовує незалежний стан.
- [x] Повторна або застаріла синхронізація не повертає старе значення. UI доступний screen reader; серверний і компонентний тести перевіряють історію без push.
