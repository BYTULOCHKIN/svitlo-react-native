# 04. Регіональні зміни графіка: push та історія

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 10, 11, 14, 16, 21, 36.

## What to build

Зміна змісту графіка створює картку «Графік змінено» та регіональний push незалежно від черги користувача. Виправлення лише минулих годин зберігається в історії без push.

## Acceptance criteria

- [ ] Детектор порівнює нормалізований зміст усіх повернутих черг; зміна часу публікації або порядку рядків без зміни станів не створює повідомлення.
- [ ] Поточні/майбутні зміни надсилаються також інсталяції, чергу якої не змінено; лише минулі зміни не надсилаються, але відображаються.
- [ ] Публікація та зміна мають різні типи, заголовки, час події та дату графіка; повторний cron не дублює історію.
- [ ] Інтеграційні й компонентні тести перевіряють сьогодні/завтра, регіональну аудиторію та межу між минулим і майбутнім.
