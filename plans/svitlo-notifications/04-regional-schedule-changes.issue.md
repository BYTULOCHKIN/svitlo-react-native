# 04. Регіональні зміни графіка: push та історія

Тип: AFK.

Статус: реалізовано, перевірено локально та на тестовій D1, розгорнуто на Render і production D1 9 листопада 2026 року.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 10, 11, 14, 16, 21, 36.

## What to build

Зміна змісту графіка створює картку «Графік змінено» та регіональний push незалежно від черги користувача. Виправлення лише минулих годин зберігається в історії без push.

## Acceptance criteria

- [x] Детектор порівнює нормалізований зміст усіх повернутих черг; зміна часу публікації або порядку рядків без зміни станів не створює повідомлення.
- [x] Поточні/майбутні зміни надсилаються також інсталяції, чергу якої не змінено; лише минулі зміни не надсилаються, але відображаються.
- [x] Публікація та зміна мають різні типи, заголовки, час події та дату графіка; повторний cron не дублює історію.
- [x] Інтеграційні й компонентні тести перевіряють сьогодні/завтра, регіональну аудиторію та межу між минулим і майбутнім.

## Перевірка реалізації

На 9 листопада 2026: 43 серверні тести й 26 тестів мобільних сповіщень пройшли; type-check, lint і збірка Node backend також пройшли. Реальна тестова D1 підтвердила міграцію зі збереженням історії, push ticket, кількості записів і послідовності подій, без порушень foreign key. На ній перевірено майбутню зміну, мовчазне виправлення минулого, повторну зміну та restart без дублювання. Expo delivery у цьому сценарії підмінено; синтетичних production-повідомлень не створено.

Production: перед міграціями збережено приватну SQL-резервну копію. Офіційний D1 SQL import перевірено на rollback у разі помилки на тестовій базі, після чого ним атомарно застосовано 0006–0007. Збережено 2 події, 11 записів історії, 3 записи outbox, 6 інсталяцій та 6 налаштувань доставки, 3 snapshot і 1 backend job; foreign key violations — 0, AUTOINCREMENT не зменшився. Тимчасовий Worker для тестової міграції видалено; нової HTTP-точки доступу до production D1 не додано.

Render: коміт `727522b`, deploy `dep-dbopnic9v7es738126vg` — live о 10:12 UTC. Перевірка о 10:12:52 UTC підтвердила реальне отримання HTML через WireGuard за 919 мс, 12 підчерг, API `stale: false` та оновлення `verifiedAt` реальним cron після запуску нової версії. Синтетичні зміни в production не створювались; розгалуження push/історії підтверджені інтеграційними тестами та реальною тестовою D1 з mock Expo.
