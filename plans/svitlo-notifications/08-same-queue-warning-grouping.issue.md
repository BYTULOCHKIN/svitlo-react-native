# 08. Одне попередження для локацій спільної черги

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 7, 8.

## What to build

Дві або більше ввімкнених локацій однієї черги й одного відключення отримують один push та один запис із усіма відповідними назвами.

## Acceptance criteria

- [ ] Групування виконується в межах інсталяції, черги та відключення; однаковий час різних черг не об’єднує повідомлення.
- [ ] Вимкнені/видалені локації не потрапляють у нове попередження; актуальний перелік перевіряється перед формуванням.
- [ ] Повний перелік доступний у картці; довгі назви переносяться. Push за потреби стисло передає перелік без перевищення розміру payload.
- [ ] Повторні й конкурентні запуски зберігають один логічний запис; тест проходить від підписок до доставки та доступної картки з великим шрифтом.
