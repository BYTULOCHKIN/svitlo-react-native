# 07. Попередження для всіх локацій та їхні перемикачі

Тип: AFK.

Статус: реалізовано й розгорнуто; автоматичні перевірки та тестова D1 PASS. Production APK build 3 встановлено на Samsung: перемикачі, реальні згруповані push та 200%/320 dp перевірені; ручне перемикання TalkBack підтверджене сервером.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 3, 4, 5, 6, 12, 35.

## What to build

Усі збережені локації мають незалежні попередження; додавання, редагування, вимкнення та видалення синхронізуються з серверним планом. Наявні дані безпечно мігрують.

## Acceptance criteria

- [x] Нова й мігрована локація отримують увімкнений прапорець; назви, черги, іконки та активний вибір збережені.
- [x] Перемикач локації вимикає тільки її нові попередження; історичні записи залишаються. Загальний перемикач графіків не змінює цієї поведінки.
- [x] Зміна черги перебудовує її майбутні завдання, видалення скасовує їх після синхронізації; історія зберігає початкові назви/черги.
- [x] Сценарій із кількома різними чергами перевірено від форми та API до різних push і карток. Версії налаштувань не дозволяють застарілому запиту відновити видалену підписку.
