# 07. Попередження для всіх локацій та їхні перемикачі

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 3, 4, 5, 6, 12, 35.

## What to build

Усі збережені локації мають незалежні попередження; додавання, редагування, вимкнення та видалення синхронізуються з серверним планом. Наявні дані безпечно мігрують.

## Acceptance criteria

- [ ] Нова й мігрована локація отримують увімкнений прапорець; назви, черги, іконки та активний вибір збережені.
- [ ] Перемикач локації вимикає тільки її нові попередження; історичні записи залишаються. Загальний перемикач графіків не змінює цієї поведінки.
- [ ] Зміна черги перебудовує її майбутні завдання, видалення скасовує їх після синхронізації; історія зберігає початкові назви/черги.
- [ ] Сценарій із кількома різними чергами перевірено від форми та API до різних push і карток. Версії налаштувань не дозволяють застарілому запиту відновити видалену підписку.
