# 09. Скасування й перенесення попереджень в історії

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 15, 28, 29, 35.

## What to build

Зміна графіка скасовує застарілі майбутні завдання й оновлює вже сформовану картку позначкою «Скасовано» або «Час змінено». Користувач бачить початковий план, актуальний час та окрему подію зміни.

## Acceptance criteria

- [ ] Перед доставкою перевіряються версія графіка й підписка; застаріле завдання не відправляється навіть за конкурентної зміни.
- [ ] Старий запис зберігає початкові дані й отримує актуальну позначку; неоднозначне перенесення не створює вигаданого зіставлення відключень.
- [ ] Нове попередження для перенесеного початку можливе тільки якщо його момент мінус 10 хвилин ще попереду.
- [ ] API повертає оновлення старих записів, а не лише нові ID; клієнт змінює картку без дубліката. Перевірено окремий запис регіональної зміни й серверно-клієнтські перегони.
