# 03. Щохвилинні публікації графіків на сьогодні й завтра

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 9, 10, 16, 21, 23, 36.

## What to build

Спільний серверний цикл перевіряє дві дати та повідомляє про першу публікацію нового дня: push для підключених інсталяцій і картка «Опубліковано графік». Збережений базовий стан переживає перезапуск.

## Acceptance criteria

- [ ] Датоване джерело опитується раз на 60 секунд для сьогодні й завтра за Europe/Kyiv; кількість запитів не залежить від кількості користувачів.
- [ ] Валідна перша публікація нового дня створює одну подію та історію вже підключених інсталяцій, включно з відсутнім дозволом або токеном.
- [ ] Початковий snapshot уже відомого дня та повторна незмінна відповідь не запускають стару публікацію. Різниця оформлення HTML не створює подію.
- [ ] Порожній HTTP 200, неправильна дата, помилка та невідомий HTML зберігають останній валідний стан; підтверджена відсутність відключень розпізнається окремо. Перевірено весь шлях до push і картки.
