# 06. Попередження за 10 хвилин для однієї локації

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 1, 2, 7, 15, 16, 21, 22, 36.

## What to build

Для однієї збереженої локації сервер планує попередження про підтверджений стан off, зберігає його в історії та надсилає push за 10 хвилин. Картка містить дату, чергу, локацію й абсолютний час.

## Acceptance criteria

- [ ] Контрольований час доводить формування за 10 хвилин, роботу 24/7 і відсутність попереджень для possible, unknown та відновлення.
- [ ] Якщо графік уперше отримано після потрібного моменту, попередження пропущено; подія публікації/зміни залишається. Після простою наздоганяння немає.
- [ ] За збоїв джерела попередження використовує кеш лише за останньої успішної перевірки ≤5 хвилин тому; невдала перевірка не оновлює цей час.
- [ ] Дата/час обчислюються для Києва з переходом через північ і зміною UTC-зсуву; строк push закінчується до початку відключення. Унікальність завдання й актуальна версія перевіряються перед відправленням.
- [ ] Unit та інтеграційні тести покривають часові межі й свіжість; native/компонентна перевірка показує запис незалежно від доставки.
