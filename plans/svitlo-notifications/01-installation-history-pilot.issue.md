# 01. Пілот: серверна подія → історія без акаунта

Тип: AFK.

Статус: реалізовано; локальні unit, інтеграційні та компонентні перевірки пройдені. Android APK зібрано; native-сценарій на Samsung очікує підключення пристрою.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 21, 22, 32, 34.

## What to build

Після першого налаштування інсталяція реєструється без логіна й отримує власну історію. Контрольована публікація валідного графіка проходить через серверне сховище та API до мінімальної картки на вкладці «Сповіщення». Це локально перевірюваний наскрізний пілот, який не потребує хмарних доступів.

## Acceptance criteria

- [x] Інсталяція має стабільний ідентифікатор і секрет доступу; повторна реєстрація не дублює її, чужа історія недоступна.
- [x] Історія починається з успішного підключення; попередні регіональні події не додаються. Дані події записані до будь-якої спроби доставки.
- [x] Тестовий сценарій із валідним графіком створює один запис, повертає його через API та показує картку; контрольоване джерело ізольоване від production.
- [x] Є стани завантаження, порожньої історії й помилки з повтором. Unit, інтеграційна та компонентна перевірки доводять поведінку, включно з повторним отриманням без дублікатів.

## Validation

11 жовтня 2026 року: type-check, lint, design:check та всі 31 комбінація design:contrast PASS. Jest: 26 suites / 130 tests PASS; серверний Node runner: 7 integration tests PASS. Перевірено реальну SQLite, захоплений HTML, API, мобільний клієнт, атомарний rollback, власний доступ, відсутність старих подій навіть за однакових timestamps, перезапуск і пагінацію. Компонентні тести підтверджують loading, empty, error/retry, картку та відсутність дублікатів.

Локальний HTTP API відповідає на health. Android development APK із SecureStore зібрано успішно. [Підготовлені native flows](../../.maestro/svitlo-notifications/README.md) ще не запущено: ADB не показує підключених пристроїв. iOS, TalkBack/VoiceOver, реальний push та хмарні квоти цією задачею не підтверджені. [Інструкція локального пілота](../../server/notifications/README.md).
