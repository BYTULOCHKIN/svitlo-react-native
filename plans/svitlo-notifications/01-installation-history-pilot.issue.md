# 01. Пілот: серверна подія → історія без акаунта

Тип: AFK.

Статус: не почато.

Джерело: [PRD](../svitlo-notifications.prd.md). [Погоджене розбиття](../svitlo-notifications.issues-proposal.md).

User stories PRD: 21, 22, 32, 34.

## What to build

Після першого налаштування інсталяція реєструється без логіна й отримує власну історію. Контрольована публікація валідного графіка проходить через серверне сховище та API до мінімальної картки на вкладці «Сповіщення». Це локально перевірюваний наскрізний пілот, який не потребує хмарних доступів.

## Acceptance criteria

- [ ] Інсталяція має стабільний ідентифікатор і секрет доступу; повторна реєстрація не дублює її, чужа історія недоступна.
- [ ] Історія починається з успішного підключення; попередні регіональні події не додаються. Дані події записані до будь-якої спроби доставки.
- [ ] Тестовий сценарій із валідним графіком створює один запис, повертає його через API та показує картку; контрольоване джерело ізольоване від production.
- [ ] Є стани завантаження, порожньої історії й помилки з повтором. Unit, інтеграційна та компонентна перевірки доводять поведінку, включно з повторним отриманням без дублікатів.

## Blocked by

None - can start immediately.
